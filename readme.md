# (Placeholder) — Plataforma de Gestão de Tarefas e Fluxos de Trabalho

Projeto desenvolvido como Projeto Integrador (PI) em parceria com a **Pinhalense**, com o objetivo de criar uma plataforma web de gestão de tarefas e fluxos de trabalho colaborativos.

## Sobre o Projeto

### Objetivo

Desenvolver uma plataforma web de gestão de tarefas e fluxos de trabalho colaborativos, inspirada na simplicidade de quadros do **Trello** e na rastreabilidade de processos/encaminhamentos do **Fluig**.

### Problema que Resolve

Centraliza a comunicação e as solicitações entre setores operacionais (ex: PCP, Manutenção, RH), evitando que pendências se percam em e-mails ou mensagens instantâneas.

### Como Funciona

1. O usuário cria uma **Atividade** dentro de um **Grupo/Setor** (ex: PCP).
2. Define a descrição da atividade, o responsável inicial e pode anexar arquivos.
3. Conforme a tarefa progride, o responsável registra um **histórico/comentário** e **encaminha/atribui** a atividade para outro usuário ou setor, dando continuidade ao fluxo de trabalho.

##  Funcionalidades

- [x] Criação de atividades por grupo/setor
- [x] Atribuição de responsáveis
- [x] Anexo de arquivos às atividades
- [x] Histórico de comentários e encaminhamentos
- [x] Encaminhamento de atividades entre usuários/setores
- [x] Login de usuários
- [x] Upload de dados/arquivos


## Tecnologias Utilizadas

- **JavaScript**
