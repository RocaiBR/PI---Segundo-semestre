# Plataforma de Gestão de Tarefas e Fluxos de Trabalho — Estudo de Caso

## RNF01 — Disponibilidade

O sistema deve estar disponível na maior parte do tempo, exceto em momentos de manutenção programada.

## RNF02 — Segurança

Todos os dados sensíveis, como arquivos anexados e informações de usuários, serão armazenados de forma protegida.

## RNF03 — Usabilidade

A interface deve ser intuitiva e responsiva, inspirada na simplicidade de ferramentas como o Trello.

## RNF04 — Integridade do Histórico

O histórico de comentários e encaminhamentos das atividades não poderá ser apagado ou alterado.

## RNF05 — Desempenho

O sistema deve responder às ações do usuário sem atrasos perceptíveis.

## RNF06 — Escalabilidade

A arquitetura deve suportar a adição de novos setores e usuários sem perda de desempenho.
