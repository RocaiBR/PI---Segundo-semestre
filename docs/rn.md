# Plataforma de Gestão de Tarefas e Fluxos de Trabalho — Requisitos Não Funcionais

## RN01 — Segurança de Acesso

O sistema exigirá login e autenticação de usuários para garantir que apenas pessoas autorizadas acessem as atividades e os arquivos anexados.

## RN02 — Rastreabilidade do Histórico

O histórico de comentários e encaminhamentos de cada atividade não poderá ser apagado ou alterado, garantindo a rastreabilidade completa do fluxo de trabalho.

## RN03 — Usabilidade

A interface será simples e intuitiva, inspirada na facilidade de uso de ferramentas como o Trello, reduzindo a curva de aprendizado dos usuários.

## RN04 — Armazenamento de Arquivos

O sistema irá armazenar de forma segura os arquivos anexados às atividades, com limite de tamanho definido por upload.

## RN05 — Disponibilidade

A plataforma manterá disponibilidade de acesso durante o horário de operação da empresa parceira, evitando indisponibilidades que prejudiquem o fluxo de atividades.

## RN06 — Infraestrutura em Nuvem

O sistema será hospedado em ambiente de nuvem, com modelo de serviço (IaaS/PaaS/SaaS) definido conforme levantamento de custos em andamento, tendo a AWS Academy como opção principal.
