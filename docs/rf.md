# Requisitos Funcionais (RF)

Plataforma de Gestão de Tarefas e Fluxos de Trabalho — Projeto Integrador (PI) em parceria com a Pinhalense.

| Código | Requisito | Descrição |
|--------|-----------|-----------|
| RF01 | Login de usuários | O sistema deve permitir que o usuário realize login na plataforma por meio de credenciais (usuário/senha). |
| RF02 | Cadastro de grupos/setores | O sistema deve permitir a criação e organização de grupos/setores (ex: PCP, Manutenção, RH) para agrupar atividades relacionadas. |
| RF03 | Criação de atividades | O sistema deve permitir que o usuário crie uma nova atividade dentro de um grupo/setor específico. |
| RF04 | Descrição da atividade | O sistema deve permitir o preenchimento da descrição detalhada de cada atividade criada. |
| RF05 | Definição de responsável inicial | O sistema deve permitir a atribuição de um responsável inicial no momento da criação da atividade. |
| RF06 | Upload de arquivos | O sistema deve permitir o anexo (upload) de arquivos às atividades. |
| RF07 | Registro de histórico/comentários | O sistema deve permitir que o responsável por uma atividade registre comentários e atualizações de andamento, mantendo um histórico. |
| RF08 | Encaminhamento de atividades | O sistema deve permitir que o responsável atual encaminhe/atribua a atividade a outro usuário ou setor, dando continuidade ao fluxo de trabalho. |
| RF09 | Notificação de encaminhamento | O sistema deve notificar o novo responsável ao receber uma atividade encaminhada. |
| RF10 | Rastreabilidade do fluxo | O sistema deve manter e exibir o histórico completo de encaminhamentos de uma atividade, permitindo consulta a qualquer momento. |
| RF11 | Finalização de atividades | O sistema deve permitir que uma atividade seja marcada como finalizada/concluída. |
| RF12 | Upload de dados/arquivos gerais | O sistema deve permitir o upload de dados/arquivos diversos vinculados às atividades ou setores. |
